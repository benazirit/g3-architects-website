# G3 Architects Website Practice

## Overview

This project was developed as part of my frontend web development practice while following the Programming Hero Batch 10 curriculum.

The objective of this project was to build a responsive landing page for a fictional architecture company using HTML and CSS, with a focus on layout design and responsive user interfaces.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive landing page
- Modern user interface
- Hero section
- Team section
- Features section
- Facts section
- Sponsors section
- Mobile-friendly layout

## What I Learned

Through this project, I improved my understanding of:

- Semantic HTML
- CSS Flexbox
- CSS Grid
- Responsive web design
- Layout planning
- Organizing frontend project files
